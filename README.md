# Fencing Referee App

A cross-platform fencing scorekeeper and referee console built for 
real competition use. Supports pool and direct elimination bouts 
across Foil, Épée, and Sabre disciplines.

## Features
- [ ] Pool & DE bout modes (5pt / 15pt)
- [ ] FIE rules reference with discipline filtering
- [ ] Real-time multi-device sync via WebSockets
- [ ] Installable PWA (mobile & desktop)
- [ ] Native mobile app via Capacitor
- [ ] Desktop app via Electron

## Tech Stack
- React + Vite (frontend)
- Express + Node.js (backend)
- MongoDB + Mongoose (database)
- Socket.io (real-time sync)
